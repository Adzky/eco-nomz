# Eco-Nomz

Surplus-food marketplace (Spring Boot + PostgreSQL). Source: https://github.com/Adzky/eco-nomz

This Space builds the app from the GitHub repository. All credentials are set as Space **Secrets**; none are stored here.

Open the app directly at `https://<username>-<space-name>.hf.space`. It doesn't load inside the embedded Hugging Face page, because the app blocks being framed.
